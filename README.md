Он необходим, чтобы при перезагрузке страниц или переходе по внутренним маршрутам в Telegram Mini App не возникала ошибка 404, так как сервер перенаправляет все запросы на главный index.html.

5. Backend: Купить аренду виртуального сервера (Минимальные требования: 2 ГБ ОЗУ, 1 Ядро, условно 10-15 Гб диска, OS: Ubuntu 24.04 (Можно взять другой дистрибутив по желанию), если есть возможность заранее предустановить Docker), после дождаться получения IP-адреса, имя пользователя (root) и пароль для входа.

   1. Использовать любой SSH-клиент (Putty, SmarTTY к пример) и подключиться к серверу по ssh.
   2. По протоколу SCP переместить остальные файлы (nstu_auth.py, main.py, requirements.txt, dockerfile) на виртуальный сервер в отдельную рабочую директорию (рекомендуется создать папку /opt/bot или /root/app, чтобы не замусоривать корневую директорию)
   3. Зайти в Dockerfile и поменять полный путь на рабочую директорию (см. рис. 8).
      <img width="860" height="320" alt="image" src="https://github.com/user-attachments/assets/87509ad6-29b9-418f-b55a-269a36fe84f9" />

  Прим. Для варианта №2 в пункте Frontend:
    Поскольку фронтенд на Netlify всегда разворачивается по защищенному протоколу HTTPS, браузер внутри Telegram заблокирует любые запросы к бэкенду, если тот работает по обычному HTTP, поэтому в качестве быстрого решения можно использовать: trycloudflare. Он мгновенно создает публичный защищенный адрес вида https://<random-name>.trycloudflare.com и перенаправляет с него трафик на локальный порт вашего бэкенда (8000). Его можно получить в терминале, если ввести следующие команды:
     1. Для запуска/перезапуска в фоновом режиме:
        nohup npx cloudflared tunnel --url http://localhost:8000 > cloudflared.log 2>&1 &
     2. Получить актуальный URL из файла лога:
        cat cloudflared.log | grep trycloudflare.com

   В качестве улучшенной альтернативы можно получить постоянный бесплатный HTTPS (без меняющихся субдоменов). И чтобы не менять URL во фронтенде после каждого перезапуска туннеля, можно использовать сервисы вроде sslip.io, которые превращают ваш IP-адрес в доменное имя: IP_вашего_виртуального_сервера.sslip.io. Потом для него можно на сервере настроить Nginx/Caddy и выпустить бесплатный SSL-сертификат Let's Encrypt на 90 дней.
   
   Полученный URL вписать в строку (const API_BASE_URL = '';) в файле index.html, сохранить и повторить действия начиная со второго пункта в варианте №2 Frontend.
